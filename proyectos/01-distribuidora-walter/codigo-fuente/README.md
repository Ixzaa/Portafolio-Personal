# Distribuidora Walter — ASP.NET Core Web API & B2B Manager

## 📖 Descripción
Sistema backend y arquitectura RESTful para la gestión y facturación de distribución mayorista.
Desarrollado en **C# con .NET 8**, Entity Framework Core y documentación OpenAPI con Swagger.

## 🛠️ Tecnologías
- **Lenguaje:** C# 12
- **Framework:** ASP.NET Core 8.0 Web API
- **ORM:** Entity Framework Core
- **Base de Datos:** SQL Server / In-Memory Db
- **Documentación:** Swagger / OpenAPI

## 🚀 Cómo abrir y ejecutar en Visual Studio 2022
1. Abre **Visual Studio 2022**.
2. Selecciona **"Abrir un proyecto o una solución"** (o crea un proyecto ASP.NET Core Web API y copia estos archivos).
3. Presiona `F5` o el botón verde **"Iniciar"** (con IIS Express o Kestrel).
4. El navegador abrirá automáticamente la interfaz interactiva de Swagger en `https://localhost:7001/swagger`.
