# AgroVerde — Auditoría y Gobierno de TI con COBIT 2019

## 📖 Descripción
Marco metodológico y herramientas de evaluación de capacidad de procesos (CMMI niveles 0 a 5) aplicado a la transformación digital y seguridad IoT de la agroindustria moderna.

## 🛠️ Tecnologías y Estándares
- **Marco Rector:** ISACA COBIT 2019 (Objetivos EDM, APO, BAI, DSS, MEA)
- **Madurez de Procesos:** CMMI V2.0 Capability Levels
- **Herramienta Interactiva:** Dashboard de análisis de brechas con gráfico de radar en Canvas

## 🚀 Cómo revisar en Visual Studio 2022
1. Abre esta carpeta en **Visual Studio 2022**.
2. Puedes inspeccionar y editar los documentos de gobernanza en Markdown (`.md`) y la estructura de ponderación en JSON (`.json`) con soporte nativo de validación de sintaxis en el IDE.
