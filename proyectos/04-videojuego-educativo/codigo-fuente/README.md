# MathQuest 2D — Videojuego Educativo con Unity & C#

## 📖 Descripción
Videojuego interactivo de plataformas 2D diseñado para el refuerzo del pensamiento lógico-matemático y algorítmico mediante mecánicas de gamificación.
Construido con la arquitectura basada en componentes de **Unity Engine** y scripts escritos en **C#**.

## 🛠️ Tecnologías y Arquitectura
- **Motor:** Unity 2022 LTS / Unity 6
- **Lenguaje:** C# (.NET Standard)
- **Física:** Rigidbody2D, BoxCollider2D, Raycast Ground Check
- **Patrones de Diseño:** Singleton (`GameManager`), Observer (`UnityEvents`), Component-Based Architecture
- **Audio:** Web Audio API (versión web) y AudioSource de Unity

## 🚀 Cómo abrir y editar en Visual Studio 2022
1. Abre tu proyecto en **Unity Hub / Unity Editor**.
2. Ve a **Edit -> Preferences -> External Tools**.
3. Selecciona **Visual Studio 2022** como tu *External Script Editor*.
4. Al hacer doble clic en cualquiera de estos scripts desde Unity, se abrirán en Visual Studio con soporte de IntelliSense, depuración paso a paso y análisis de rendimiento para Unity.
