# MediCare Móvil — Flutter & Dart Cross-Platform

## 📖 Descripción
Aplicación móvil diseñada para iOS y Android para el control de tratamientos farmacológicos, signos vitales y programación de consultas médicas.
Implementa el patrón de arquitectura **State Management con Provider** y Material 3 UI.

## 🛠️ Tecnologías
- **Framework:** Flutter 3.x
- **Lenguaje:** Dart 3.x
- **Gestor de Estado:** Provider (`ChangeNotifier`)
- **Diseño:** Material Design 3 con soporte modo oscuro

## 🚀 Cómo ejecutar localmente
1. Clona o abre esta carpeta en tu editor preferido (Visual Studio 2022 con extensión Flutter, o VS Code / Android Studio).
2. Abre la terminal y descarga dependencias:
   ```bash
   flutter pub get
   ```
3. Ejecuta en tu emulador Android, simulador iOS o en Chrome:
   ```bash
   flutter run -d chrome
   ```
