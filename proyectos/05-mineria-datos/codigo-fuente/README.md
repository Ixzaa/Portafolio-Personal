# Comparativa de Modelos de Machine Learning & Minería de Datos

## 📖 Descripción
Estudio comparativo riguroso de algoritmos supervisados de clasificación aplicados a la evaluación de riesgo y predicción de comportamiento crediticio.
Incluye preprocesamiento de características continuas y categóricas, validación cruzada y análisis de trade-off entre sesgo y varianza.

## 🛠️ Tecnologías
- **Lenguaje:** Python 3.10+
- **Librerías:** Scikit-Learn, Pandas, NumPy
- **Métricas:** Confusion Matrix, ROC-AUC Curve, F1-Score Ponderado

## 🚀 Cómo ejecutar en Visual Studio 2022 / VS Code
1. Abre esta carpeta en **Visual Studio 2022** (con la carga de trabajo de Python instalada).
2. Abre la terminal integrada de VS y crea un entorno virtual:
   ```bash
   python -m venv env
   .\env\Scripts\activate
   pip install -r requirements.txt
   ```
3. Ejecuta el análisis:
   ```bash
   python analisis_modelos_ml.py
   ```
